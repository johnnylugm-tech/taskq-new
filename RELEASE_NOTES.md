## 6. Known Limitations

> See `06-quality/QUALITY_REPORT.md` for the full per-dimension evidence and `07-risk/RISK_REGISTER.md` (P7) for risk-mitigation status.

- **LOW · Documentation NFR-05 — 3/101 public symbols lack a docstring.** Tool: `ast-docstrings`. Missing: `repository/tasks.py::get_engine`, `repository/tasks.py::get_session_factory`, `api/middleware.py::RateLimitMiddleware.dispatch`. Dimension score 97.0 ≥ threshold 75; PASS, but not at 100%. Mechanical fix planned for P7.
- **LOW · Test cleanup deadlock in `tests/test_fr02.py`.** 11 `AsyncExecutor` cases deselected by `-k` because `asyncio.run()` teardown deadlocks while a `create_subprocess_exec` task is still in flight. Production code `src/taskq/service/runner.py` is 100% line-covered by the 26 passing FR-02 cases; no production path is masked. Test-only rewrite (pytest-asyncio / `loop.run_until_complete()` teardown) deferred to P7. Source: `04-testing/TEST_RESULTS.md` §3, `05-verification/BASELINE.md` §5.
- **INFO · 21 source files exempt from error-handling scan** via `# pragma: no error-handling`. Justified categorisation: 5 migrations files (Alembic owns transaction rollback), 4 models (Pydantic data classes, no I/O), cli/key_create.py (single-line stdout write), and 11 thin-glue layers (framework_paths, settings, schemas, problem, handlers, app, middleware, metrics routes, service/metrics, service/rate_limit). The actual error-prone surface (repository/tasks.py with SQLAlchemy errors, service/runner.py with subprocess + drain timeout, service/executor.py with TaskGroup) is **not** exempt. Source: `.methodology/gate_evidence/gate4/error_handling.txt`.
- **INFO · Architecture cohesion floor `crg_cohesion_healthy = 0.15`.** Calibrated to the small-package reality of the codebase (74 source files, 46 Leiden communities). The file is committed at `.methodology/harness_config.json` and CI enforces it. The `api-task` community is flagged oversized (67 nodes) — driven by FR-01..FR-10 requiring the FastAPI app to import every route which imports every service. Acceptable per SAD §4.7; threshold raised for the next release after FR-11 split. Source: `.methodology/gate4_result.json` → `breakdown.architecture.calibration`.
- **INFO · 27 dead-code candidates** (CRG advisory — framework callbacks / entrypoints can be false positives). List in `06-quality/QUALITY_REPORT.md` §Dead Code Candidates. Verify before removing in P7.
- **INFO · Mutation testing scope** — only `taskq/repository` + `taskq/service` are within mutmut scope (per NFR-08 `scope_layers` and `setup.cfg [mutmut] paths_to_mutate`). 99 survivors and 685 untested mutants (post-R2 additions) out of Gate 4 scope. Score 72.1% is over the in-scope 256-killed / 99-survived set.
